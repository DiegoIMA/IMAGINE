## 04 · Comunicação visual: arquivos do cliente

A aba do cliente ganha uma área de arquivos. A IA confere se cada arquivo está apto para imprimir, e a cadência é diária, porque cada dia de atraso mexe no cronograma de produção.

| O que a IA confere no arquivo | Critério (a Comunicação visual define os valores) |
| :---- | :---- |
| Formato | o formato aceito pela Comunicação visual (ex.: PDF, AI ou EPS) |
| Resolução | suficiente para o tamanho final de impressão |
| Cor | modo de cor para impressão |
| Medidas | iguais às do projeto, com sangria |
| Fontes | convertidas em curvas ou anexadas |
| Corte | linha de corte separada, quando houver recorte |

### Cadência dos alertas

| Quando | O que acontece | Resultado |
| :---- | :---- | :---- |
| Dia 0 | cliente publica; a IA confere no mesmo dia | aprovado: segue para formatação |
| Dia 0 · reprovado | Portal avisa Comunicação visual, comercial e Planejamento | cliente recebe o alerta com o que corrigir e tem 1 dia |
| Dia 1 | cliente republica; a IA confere de novo | aprovado: segue; reprovado: o comercial liga e orienta |
| Cada dia de atraso | Portal recalcula o impacto no cronograma de produção | Planejamento vê o efeito nas datas das fichas |

## 05 · Audiovisual: rider técnico e conteúdos

O rider técnico é a lista de equipamentos combinada com o cliente. As medidas são conferidas com a equipe de montagem antes da produção, e os conteúdos testados e programados entram no mesmo checklist de montagem e entrega.

| Campo do rider técnico | Conteúdo |
| :---- | :---- |
| Equipamento | tela, projetor, caixa de som, mesa, iluminação etc. |
| Quantidade e especificação | modelo, tamanho, potência, resolução |
| Uso | objetivo e modo de operar combinados com o cliente |
| Conteúdo | vídeo ou arquivo que roda em cada equipamento, com o status do teste |
| Montagem | onde fica no stand e quem programa e testa no pavilhão |

### Conferência de medidas com a montagem (AUD-E4)

| Item conferido (checklist com foto) | O que confere |
| :---- | :---- |
| Telas e projeções | tamanho da tela e do nicho ou painel que a recebe, altura de instalação |
| Suportes e fixações | ponto de fixação, peso e reforço na estrutura (marcenaria ou serralheria) |
| Elétrica e cabos | posição das tomadas, passagem de cabos e ponto de energia de cada equipamento |
| Som e luz | posição das caixas, refletores e trilhos, com as distâncias do projeto |
| Acesso e ventilação | espaço para instalar, operar e ventilar os equipamentos |

Sem a conferência, as medidas podem não bater na feira, e o resultado é atraso ou retrabalho para o Audiovisual e para os outros setores. Cada item conferido tem ok e foto, como no checklist de montagem.
